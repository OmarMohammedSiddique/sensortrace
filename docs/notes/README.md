# Working notes

Dated working notes, worklogs and investigation scratch records. Name each file
`YYYY-MM-DD-topic.md` so they sort by date.

Notes record what was true when they were written and are not kept up to date. Anything that becomes
a lasting decision moves to [`../decisions/`](../decisions/), and anything a user or operator needs
moves into the main documentation. Progress on a piece of work can also go in a dated comment on its
GitHub issue.
