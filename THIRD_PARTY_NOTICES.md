# Third-party notices

SensorTrace is licensed under the Apache License 2.0 (`LICENSE`, `NOTICE`). It depends on third-party
software under its own licences. This file says where the full notices are and records the obligations
that need more than a notice.

## Where the full notices are

| What is distributed | Notices | How they are produced |
|---|---|---|
| API image (`backend/Dockerfile`) | `/srv/backend/THIRD_PARTY_NOTICES.txt`, with `LICENSE`, `NOTICE` and this file | `scripts/python_notices.py`, run with the image's own Python environment while the image is built |
| Web image (`frontend/Dockerfile`) | `/app/THIRD_PARTY_NOTICES.txt` | `frontend/scripts/third-party-notices.mjs`, run against the installed production npm packages while the image is built |
| This repository | This file, and the vendored code below | Maintained by hand |

Each generated file lists every package with its version, declared licence, source and the full text
of each licence or notice file the package ships. Because the files are written from the installed
packages during the build, they always match the image. To read them without building an image:

```bash
cd backend && uv sync --frozen --no-dev && .venv/bin/python ../scripts/python_notices.py
cd frontend && npm ci && node scripts/third-party-notices.mjs
```

The Vercel deployment runs the same packages as a hosted service and distributes no images; the
client-side JavaScript it serves is covered by the web notices.

## LGPL components

These are used as unmodified, separately replaceable libraries. Distributing an image that contains
them requires keeping their notices (done above), not preventing replacement, and offering the source.

| Component | Licence | Where | How the obligations are met |
|---|---|---|---|
| psycopg, psycopg-binary | LGPL-3.0-only (the wheel also bundles libpq, PostgreSQL licence) | API image | Separate, unmodified Python package that can be swapped with `pip`; source at https://github.com/psycopg/psycopg |
| FFmpeg inside the opencv-python-headless wheel | LGPL-2.1-or-later | API image | Shared libraries inside the unmodified wheel; only image functions are called, never video code; source at https://ffmpeg.org/download.html |
| sharp and `@img/sharp-libvips-*` | Apache-2.0 and LGPL-3.0-or-later | Not shipped | Next.js image optimisation is switched off (`images.unoptimized`), and the web image deletes these binaries from the standalone output |

This is an engineering checklist, not legal advice. Have counsel confirm it before distributing images
commercially (see `LICENSE_DECISIONS.md` and issue #8).

## Not distributed

The PRNU reference implementation used as a development-only test oracle
(`scripts/fetch_reference_implementation.sh`) is fetched at test time, is never imported by the product
and is never included in the repository or an image.
